Bidova
Product Handbook.

A practical guide to Bidova User and Bidova Manager, organized around the real program screens and safe Dropbox job workflows.

Version 9.3.20 source17 chaptersUser + ManagerPrint-friendly
Important: Bidova files into existing linked Dropbox jobs and existing scope folders. Always verify the exact save destination before confirming.
Start here / 01

Overview

Bidova is the daily estimating workspace; Bidova Manager is the restricted administration workspace.

01
Two applications

Bidova handles existing jobs, proposal intake, comparison, combining PDFs and bid history. Manager handles users, audit activity, backups, recovery, updates and diagnostics.

02
Access

Sign in with your assigned account. The protected Admin account is required to open Manager; an Estimator account is for approved daily work.

03
Before your first bid

Make sure your company’s existing Dropbox jobs are available locally, the correct root is configured, and you have permission to file bids.

Bidova User / 02

Dashboard

Use the dashboard as a starting point for daily estimating work.

01
What you will see

Use the dashboard shortcuts to reach Import & Review, Compare Proposals, Job Center and Bid History. The status line shows the app’s connection to Manager.

02
If the connection looks wrong

Check Manager and its diagnostics rather than changing project files or reinstalling immediately.

Bidova User / 03

Job Center & Dropbox

Browse existing GLR / Dropbox jobs without changing their folder structure.

01
Choose the jobs root

Open Job Center and select the local folder containing existing Dropbox jobs. The discovery view is read-only.

02
Find a job

Browse or search for the existing job you need. Inspect the available scope folders and read-only coverage.

03
Link the job

Choose LINK JOB and match the existing Dropbox job to a Bidova project record, or create an internal record if prompted. This does not create Dropbox folders.

04
Before filing

Select the linked job. If the job link or Dropbox root does not match, fix the link in Job Center before proceeding.

Bidova User / 04

New Bid & Auto-Read

Import one proposal, verify the extracted details and file safely.

01
Choose a job

Select a linked existing Dropbox job first.

02
Load a proposal

Open New Bid. Browse for a supported proposal file; PDF drag-and-drop accepts one PDF at a time.

03
Review extraction

Check company, bid amount, scope / CSI, bidder email, revision details and any project identification detected from the proposal.

04
Correct mistakes

Auto-Read is an assistant, not approval. Confirm the total is not an allowance or alternate, and verify the proposal belongs to the selected job.

05
Confirm the destination

Choose an existing scope folder. Read the exact Dropbox job, scope, filename and destination path shown in the final confirmation before saving.

06
Check the result

Confirm the saved proposal is in the correct folder. The original source file is preserved and saved filenames are made unique.

Bidova User / 05

Bulk Intake

Process multiple PDF proposals for an existing linked job.

01
Prepare

In Job Center, select and link the correct existing Dropbox job.

02
Add PDFs

Open Bulk Intake and add or drop multiple PDF proposals. New Bid drag-and-drop is for a single PDF instead.

03
Review each result

Check detected bidder, amount and scope for every file; do not assume the batch extraction is correct.

04
Resolve filing paths

Use existing GLR scope folders. Missing folders must be resolved outside the safe filing workflow; Bidova does not silently create them.

05
Finish carefully

Review warnings and destination choices before accepting a batch. Verify saved PDFs in the expected job folders.

Bidova User / 06

Compare Bids

Compare proposal PDFs without modifying job folders.

01
Quick compare

Open Compare Bids to load PDFs from anywhere. The quick comparison is read-only and does not file proposals.

02
Job folder comparison

Choose a valid existing scope folder, then select exactly two proposals to compare.

03
Review amounts

Both proposals need valid detected amounts. If the amounts are missing or surprising, open the originals and verify them.

04
Read the scope

Differences in totals do not explain exclusions, addenda or scope changes. Read both PDFs before deciding which proposal to use.

Bidova User / 07

Combine Files

Create one combined PDF from several existing PDF documents.

01
Add documents

Open Combine Files and select at least two PDFs.

02
Set the order

Use Move Up / Move Down and Remove to arrange the list. The displayed order is the output order.

03
Save

Choose COMBINE & SAVE and select a destination for the combined PDF.

04
Preservation

The original PDFs are not modified. Combining is not a replacement for filing individual proposals correctly.

Bidova User / 08

Bid History

Find saved bid records and verify where proposals were filed.

01
Filter

Open Bid History and filter by project or use the available search controls.

02
Inspect

Check the company, proposal details and Original / Revised status where shown.

03
Open

Open the saved PDF or destination folder to verify the underlying file.

04
Delete carefully

Deletion can affect the database record and, depending on the selected option, the saved PDF. Confirm the correct project and filename first.

Bidova User / 09

Settings & Email

Configure your profile and review bid safety preferences.

01
Profile

Confirm your displayed profile name and assigned account.

02
Safety

Keep warnings for missing scope, wrong scope, duplicates and large revisions enabled where available.

03
Job preferences

Use Job Center for existing Dropbox jobs. Legacy project folder settings do not override safe linked-job filing.

04
Email

Review the bidder address, subject and message before opening the default email app. Bidova prepares the message; you send it from your email program.

Bidova Manager / 10

Manager overview

Manager is the restricted administrative workspace, not the regular proposal-entry tool.

01
Access

The source states that only the protected Admin account can open Manager. A desktop shortcut by itself is not authorization.

02
Navigation

Manager includes Dashboard, Users & Access, Activity Center, Backups, Recovery, Updates, Operations Center, Diagnostics, Logs, Settings and Support & Developer.

03
Monitoring caveat

The Operations Center explicitly notes that filing alerts and Dropbox connectivity checks require additional integration; do not treat those as active alerts.

Bidova Manager / 11

Users & Access

Manage individual accounts and estimator permissions.

01
Accounts

Create users, assign Admin or Estimator roles, reset passwords and disable or re-enable access.

02
Permissions

Control access to project creation/deletion, scope editing, filing, Bulk Intake, Compare, Combine, email preparation, bid-history deletion and filing settings.

03
Safer administration

Use separate employee accounts rather than sharing the protected Admin login.

04
Deleting a user

The Manager dialog states that user deletion does not delete project files, bids or PDFs and creates a database safety backup first.

Bidova Manager / 12

Activity & Oversight

Review activity and project status across the system.

01
Activity Center

Use the activity log to understand who performed an action and when. Filter or search for relevant events.

02
Project oversight

Inspect existing project and scope coverage information in the available Manager views.

03
Operations Center

Use the available operational summary, but do not assume unimplemented Dropbox connectivity or filing alerts are running.

Bidova Manager / 13

Backups & Recovery

Protect data and understand the difference between backups and program rollback.

01
Backups

Use Manager > Backups to review or create available data backups. Keep a separate company backup of project PDFs and Dropbox files.

02
Recovery

Manager > Recovery handles program rollback from updater backups; it is not a replacement for restoring lost project documents.

03
Before major changes

Confirm you have a verified backup and know where the current job documents live.

Bidova Manager / 14

Updates

Install only approved, verified Bidova updates.

01
Check version

Open Manager > Updates and check the installed version.

02
Trusted package

The current source requires a signed update ZIP with its matching trusted bidova-approval.json alongside the unchanged ZIP, or a verified download through GitHub Check for Updates.

03
Install

Follow Manager’s update workflow and its validation messages. Do not bypass signature verification or manually overwrite program files.

04
Verify

After installation, reopen Bidova and Manager and confirm the reported versions. Data, Backups, Live and the Updater are protected by the normal updater process.

Bidova Manager / 15

Diagnostics & Support

Collect useful information without exposing customer data.

01
System information

Use Diagnostics, Logs and the available health views to investigate connection, service or application problems.

02
Support Package

A support export contains version/system details, schema and component inventory, with sensitive information excluded.

03
Developer Package

A developer export includes application source and supporting code but excludes Data, Backups, Live, database contents and bid PDFs.

04
Sharing files

Review an export before sending it outside the company, even when designed to exclude sensitive material.

Reference / 16

Daily workflow

A repeatable checklist for normal bid-processing days.

01
01 — Open

Sign in and confirm the correct account.

02
02 — Link

In Job Center, choose the existing Dropbox job and verify its Bidova link.

03
03 — Import

Open New Bid for one proposal or Bulk Intake for multiple PDFs.

04
04 — Verify

Check company, total, scope, CSI, job match, email and revision.

05
05 — File

Confirm the exact existing scope folder and final destination path.

06
06 — Review

Use Compare Bids for pricing differences and Bid History to verify saved work.

07
07 — Finish

Prepare acknowledgments as needed and check the relevant job folder.

Reference / 17

Troubleshooting

Start with the least disruptive check.

01
Job not linked

Open Job Center and link the selected existing Dropbox job to the correct Bidova record.

02
Scope folder missing

Check the Dropbox root and existing job folders. Safe filing will not create a missing GLR scope folder.

03
Wrong job warning

Stop filing and verify the proposal’s project identification against the selected linked job.

04
Auto-Read error

Correct the review fields manually and inspect the original proposal.

05
Compare missing totals

Open both PDFs and verify the amounts; comparison requires two proposals with usable totals.

06
Manager unavailable

Check sign-in role, Manager status, Diagnostics and Logs.

07
Update rejected

Use the approved signed package and matching approval file; do not extract or alter the signed ZIP.
