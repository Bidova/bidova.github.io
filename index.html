TWO WORKSPACES · ONE BID WORKFLOW

Made for estimators. Managed with care.

Bidova is the everyday estimating application. Bidova Manager provides separate administration and maintenance tools for authorized users.

01 / ESTIMATING WORKSPACE

Bidova User

For day-to-day proposal handling and organized job filing.

  • Choose linked jobs through Job Center
  • Import proposals and review Auto-Read results
  • Use Bulk Intake for multiple proposals
  • Compare revisions, combine files and revisit bid history
02 / ADMINISTRATION WORKSPACE

Bidova Manager

For designated administrators who oversee accounts and the software environment.

  • Review project oversight and activity
  • Manage user access and company policies
  • Access backup and recovery tools
  • Review diagnostics, logs and approved update packages

Manager access depends on the application’s account permissions and administrator controls; a separate installer or shortcut alone does not secure it.

YOUR PROJECT FILES

Know where each bid goes.

Bidova works with existing job folders. The filing workflow is designed around selecting the correct job, reviewing detected proposal information, and confirming the intended destination.

FILE ORGANIZATION

Linked jobs & scope folders

Job Center links an existing project location. When filing, select the correct scope and verify the destination folder rather than assuming Bidova will create a new job structure.

Example job names in the website’s Job Center image are fictional.

BEFORE YOU SAVE

Review first. Confirm second.

Check the bidder, total, scope, CSI information and revision status. Confirm the exact filing destination before saving, and keep a separate backup of important project documents.

Automatic extraction is a review aid—not a substitute for estimator verification.

Dropbox or another synced folder may be used only when its local Windows folder is available and configured correctly. Bidova is not presented as a browser-based cloud storage service. Syncing is not a substitute for backups.
