Questions

Good to know.

What is Bidova?

Bidova is a Windows desktop application focused on construction estimating and bid management.

Can I download it now?

Not yet. The first-time Windows installer is being prepared; this page will be updated when an approved build is available.

Is Bidova Manager included?

Bidova has a separate Manager application. Manager access is intended for authorized users and should not be assumed from installation alone.

Can I choose where project files are stored?

Bidova's existing workflows support project file organization. The new installer's storage selection experience is still being finalized.
