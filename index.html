FAQ

Good to know.

What is Bidova?

Bidova is a Windows desktop application focused on construction estimating, bid management, and project organization.

Can I download Bidova today?

A public installer has not been released yet. This website will be updated when an approved Windows installer is available.

Is Bidova a web application?

No. The product is designed as Windows desktop software. This website provides product information and future download access.

What is Bidova Manager?

Bidova Manager is a separate management application intended for authorized use. It is not offered as a public download here.
