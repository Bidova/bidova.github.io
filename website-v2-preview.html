Questions & answers

Good to know.

Can Bidova organize my existing project folders?

Bidova supports linking existing job folders and reviewing the destination before filing. Confirm that your setup and permissions are correct.

Is there a public download yet?

The public installer is not advertised as ready. Downloads will be published after verification.

Where can I find product instructions?

The product handbook describes the current Bidova User and Manager workflows.

Can I access the administrative dashboard?

Administrative access is separate and restricted. Use the existing admin login only if you have authorization.
